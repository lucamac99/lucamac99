🔮 Sales Forecasting Platform
Custom Time Series Modeling & Deployment
This project is a tailored solution developed for a large enterprise to automate and optimize sales forecasting using custom time series models. The system combines the power of FastAPI with a modern, lightweight interface and backend services, delivering a scalable and accessible forecasting platform.

🚀 Key Features:

- 📈 Custom Forecasting Models – Automatically trains models for multiple time series using uploaded sales and product data.
- 📤 Data Upload Interface – Simple, secure upload system that triggers model retraining and forecasting.
- 📊 Performance Visualization – Dynamic dashboards showing forecast accuracy, error metrics, and actual vs. predicted trends.
- 📦 Downloadable Results – Users can export forecast outputs in structured formats (CSV/Excel) for further analysis.
- 🔁 API-Driven Workflow – All core functions are also exposed via a FastAPI backend for integration with other internal systems.
- ☁️ Cloud Deployment – Fully deployed and managed on a cloud server via Hetzner, with process orchestration and logging.
